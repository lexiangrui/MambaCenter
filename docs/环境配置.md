# 环境配置

完整训练需要 Linux + NVIDIA GPU 与原生 CUDA 扫描；CPU 可运行 `tests/test_*.py`（torch 参考扫描）。

## Python 环境

在仓库根目录创建虚拟环境，先安装与驱动 / CUDA 匹配的 torch 与 torchvision，再装通用依赖：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

实验环境：Python 3.11、torch 2.11.0+cu130、torchvision 0.26.0、CUDA 13.0，RTX 5090（sm_120）。其他组合需重新运行 `tests/gpu_checks.py`。
不要安装旧 CenterNet requirements 中的 torch/torchvision；DCNv2 由 torchvision.ops.deform_conv2d 提供，与原 CUDA 实现的等价性由 `tests/test_dcn.py` 校验。

## 原生扫描扩展

| 使用者 | 扩展 | 构建产物 |
|---|---|---|
| mambacenter（Mamba-FPN / CP / IA） | selective_scan_cuda（mamba_ssm 2.2.6.post3） | runtime/selective-scan/packages/ |
| Mamba-YOLO | selective_scan_cuda_core | mamba-yolo/.deps/ |

构建方法见 [扫描运行时](../runtime/selective-scan/README.md) 与 [Mamba-YOLO](../mamba-yolo/README.md)。运行 mambacenter 时：

```bash
export PYTHONPATH="$PWD/runtime/selective-scan/packages:$PWD/runtime/selective-scan/mamba:$PWD"
```

## 数据与初始化权重

`data/visdrone` 指向 VisDrone2019-DET 根目录（CenterNet 数据集类读取 `<data-dir>/visdrone`）：

```text
VisDrone2019-DET/
├── VisDrone2019-DET-{train,val,test-dev}/images/
└── visdrone2019_det_{train,val,test-dev}_coco.json
```

标注转换：`python tools/visdrone2coco.py --root data/VisDrone2019-DET --splits train val`（保留类别 1–10，过滤 ignore/others，不实现官方忽略区域协议）。
所有 CenterNet 系模型用 CenterNet 的 `dla34(pretrained=True)` 加载 DLA-34 ImageNet 权重，缓存于 `$TORCH_HOME/hub/checkpoints/dla34-ba72cf86.pth`；计算节点无外网，需预先缓存。
Mamba-YOLO 的数据由 `mamba-yolo/tools/prepare_data.py` 生成。

## 集群调度

作业脚本在 `slurm/`（个人配置，不发布）：`env.sh` 设置 CUDA module、PYTHONPATH、`MC_RUNS` 与作业专属 TMPDIR；
`check.sbatch` 运行单元测试、GPU 检查、冒烟训练与显存探测；`train.sbatch` / `eval.sbatch` 为单卡训练与评测。
训练申请 `--gres=gpu:nvidia_geforce_rtx_5090:1`、16 CPU、32G 内存（单卡上限 25 CPU / 32G）。
